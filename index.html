About Resonance

Version 1.0 · BSIT-1A extended project

Resonance is a Spotify-inspired music player built with plain HTML, CSS and JavaScript. Plug in your headphones, tune in, and discover your frequencies.

  • Developers: Lavina, Linux · de la Cerna, Joseph · Bono, Chino · Canada, Miguel
  • Built with: HTML5, CSS Grid and Flexbox, JavaScript, Bootstrap Icons
  • Includes: songs, music videos, adverts, lyrics with translations, playlists and themes
  • Course: BSIT-1A
